# pacman-ghostbusters-ai
UC Berkeley CS 188 project implementing probabilistic inference to track hidden ghosts using Bayes nets, HMMs, and particle filtering.
# Pacman Ghostbusters AI

This project was completed as part of UC Berkeley CS 188: Introduction to Artificial Intelligence.

The project focuses on probabilistic inference for tracking hidden ghosts in the Pacman environment using noisy sensor readings.

## What I Implemented

- Bayes network construction
- Factor joining and variable elimination
- Exact inference with belief updates
- Hidden Markov Model state tracking
- Particle filtering for approximate inference
- Greedy action selection based on ghost belief distributions

## Technologies

- Python

## Concepts

- Bayes Networks
- Variable Elimination
- Hidden Markov Models
- Exact Inference
- Particle Filtering
- Probabilistic Reasoning

## Note

The Pacman framework and supporting code were provided by UC Berkeley CS 188. I implemented selected inference and agent components within the provided framework.
